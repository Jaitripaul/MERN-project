The system is a backend-only food ordering platform built using Node.js, Express.js, MongoDB, and 
Mongoose. 
The platform supports three user roles: 
→ Admin 
→ Restaurant Owner 
→ User 
The backend must provide secure authentication using JWT Access Token and Refresh 
Token, along with Role-Based Access Control, Secret-Key Authorization, and 
Ownership Validation.

Project Objectives 
The student needs to implement: 
❑ JWT-based Authentication 
❑ Access Token & Refresh Token 
❑ Password Hashing using bcryptjs 
❑ Role-Based Access Control 
❑ Restaurant Management 
❑ Food Item Management 
❑ Food Category Management 
❑ Cart Management 
❑ Order Management 
❑ Search & Filter 
❑ Ownership Validation 
❑ Basic Admin Management 
❑ Request Validation & Error Handling 
Technology Stack 
→ Node.js 
→ Express.js 
→ MongoDB 
→ Mongoose 
→ JWT 
→ bcryptjs 
→ Joi / Yup / Zod 
→ Multer / Cloudinary (optional) 
→ dotenv
